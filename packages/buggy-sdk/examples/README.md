# buggy-sdk examples

Six runnable example plugins, one per supported plugin kind. Each
directory is a buildable PyPI-style plugin package generated by
``buggy-sdk plugin new``.

| Directory | Kind | Entry-point group |
|-----------|------|-------------------|
| [`tool/`](tool/) | tool | `buggy.tools` |
| [`middleware/`](middleware/) | middleware | `buggy.middleware` |
| [`agent/`](agent/) | agent | `buggy.agents` |
| [`callback/`](callback/) | callback | `buggy.callbacks` |
| [`skill/`](skill/) | skill | `buggy.skills` |
| [`prompt/`](prompt/) | prompt | `buggy.prompts` |

## Try one

```bash
cd middleware
uv build
pip install dist/*.whl

python -c "from importlib.metadata import entry_points; print(entry_points(group='buggy.middleware'))"
```

## Regenerate

All six were generated by the SDK scaffolder. To regenerate (or to
scaffold your own), run from the workspace root:

```bash
uv run buggy-sdk plugin new \
    --kind=middleware \
    --name=my-plugin \
    --path=./my-plugin
```
